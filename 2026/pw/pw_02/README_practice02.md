### 2.3. Служебный код или ошибка ввода?

Пропуск в выгрузке часто не пустая ячейка, а **служебное значение**. Поэтому `isna().sum() = 0` ещё не означает, что пропусков нет.

- **Служебный код:** одно и то же невозможное значение, которое повторяется очень часто. Это договорённость системы:
  «нет данных» → пропуск, флаг `missing_code`.
- **Ошибка ввода:** разные значения чуть выше шкалы, по несколько раз каждое. Значение ошибочно → пропуск, флаг `out_of_range`.

В обоих случаях строка **остаётся** в данных, исходное значение сохраняется в `score_raw`.

### 2.4. Показатели качества

| Показатель | Как считаем |
|---|---|
| **C** — полнота | доля строк, где `score` известен (не пусто и не служебный код) |
| **V** — валидность | доля значений в шкале 0–100 **среди заполненных** |
| **U** — уникальность | число уникальных ключей `(id_assessment, id_student)` / число строк |
| **S** — согласованность | доля строк, где тип задания записан по словарю `{TMA, CMA, Exam}` и нет противоречия «Withdrawn + Exam» |

$$DQ = 0{,}35C + 0{,}30V + 0{,}20U + 0{,}15S$$

Веса — учебная договорённость, а не стандарт. Высокое DQ может скрывать серьёзную проблему в одном измерении.

### 2.5. Порядок конвейера очистки

```text
0. raw-срез варианта
1. удалить точные дубли          (строка повторяется целиком)
2. привести типы                 (текст → числа; '?' в сроке → NaN)
3. удалить логические дубли      (тот же ключ, другой event_id; оставить первую доставку)
4. коды пропуска и диапазон score (значение → NaN + флаг; строку НЕ удалять)
5. нормализовать категории       (tma, Tma → TMA)
6. признаки и флаги              (days_late, withdrawn_exam)
```

Порядок важен: если посчитать средний балл до шага 4, служебные коды исказят результат; если не удалить дубли, часть студентов получит лишний вес.

### 2.6. pandas ↔ GoogleSQL

| pandas | GoogleSQL |
|---|---|
| `pd.to_numeric(x, errors="coerce")` | `SAFE_CAST(x AS INT64)` |
| `df.drop_duplicates()` | `SELECT DISTINCT *` |
| `sort_values(...).drop_duplicates(subset=KEY, keep="first")` | `QUALIFY ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...) = 1` |
| `x.isin([...])` | `x IN (...)` |
| `(cond).sum()` | `COUNTIF(cond)` |
| `str.strip().str.upper()` | `UPPER(TRIM(x))` |
| `quantile(0.25)` | `PERCENTILE_CONT(x, 0.25) OVER ()` |

### Ключевой запрос: clean-слой как представление

```sql
CREATE OR REPLACE VIEW `YOUR_PROJECT_ID.learning_analytics.p02_clean` AS
WITH no_exact AS (                       -- шаг 1: точные дубли
  SELECT DISTINCT * FROM `YOUR_PROJECT_ID.learning_analytics.p02_raw`
),
typed AS (                               -- шаг 2: типы и служебные коды
  SELECT
    event_id,
    code_module,
    code_presentation,
    SAFE_CAST(id_assessment AS INT64)                    AS id_assessment,
    assessment_type                                      AS assessment_type_raw,
    SAFE_CAST(NULLIF(assessment_deadline, '?') AS INT64) AS assessment_deadline,
    SAFE_CAST(weight AS FLOAT64)                         AS weight,
    SAFE_CAST(id_student AS INT64)                       AS id_student,
    SAFE_CAST(date_submitted AS INT64)                   AS date_submitted,
    SAFE_CAST(is_banked AS INT64)                        AS is_banked,
    score                                                AS score_raw,
    IF(score IN ('?', '999', '-1'), NULL, SAFE_CAST(score AS INT64)) AS score_int,
    final_result
  FROM no_exact
),
dedup AS (                               -- шаг 3: логические дубли по ключу
  SELECT * FROM typed
  WHERE TRUE
  QUALIFY ROW_NUMBER() OVER (
    PARTITION BY id_assessment, id_student
    ORDER BY event_id
  ) = 1
)
SELECT                                   -- шаги 4–6: правила, нормализация, признаки
  event_id,
  code_module,
  code_presentation,
  id_assessment,
  CASE UPPER(TRIM(assessment_type_raw))
    WHEN 'TMA'  THEN 'TMA'
    WHEN 'CMA'  THEN 'CMA'
    WHEN 'EXAM' THEN 'Exam'
  END                                                    AS assessment_type,
  assessment_deadline,
  weight,
  id_student,
  date_submitted,
  is_banked,
  score_raw,
  IF(score_int BETWEEN 0 AND 100, score_int, NULL)       AS score,
  CASE
    WHEN score_raw IS NULL OR score_raw IN ('?', '999', '-1') THEN 'missing_code'
    WHEN score_int IS NULL OR score_int NOT BETWEEN 0 AND 100 THEN 'out_of_range'
    ELSE 'ok'
  END                                                    AS score_flag,
  final_result,
  date_submitted - assessment_deadline                   AS days_late,
  (final_result = 'Withdrawn'
   AND UPPER(TRIM(assessment_type_raw)) = 'EXAM')        AS withdrawn_exam
FROM dedup;
```
