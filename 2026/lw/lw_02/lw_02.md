## 4. Теоретический минимум с пояснениями

### K-Means: «раскладываем учеников по похожести»

Алгоритм выбирает $k$ центров, относит каждого ученика к ближайшему центру, затем переносит центры в середину своих групп и повторяет, пока группы не перестанут меняться. Он минимизирует сумму квадратов расстояний до центров:

$$
J = \sum_{j=1}^{k} \sum_{x_i \in C_j} \lVert x_i - c_j \rVert^2 .
$$

Здесь $c_j$ — центроид кластера $j$. Величина `inertia_` в scikit-learn — это и есть $J$. При росте $k$ она **всегда** уменьшается, поэтому одной инерции для выбора $k$ недостаточно.

### StandardScaler: зачем масштабировать

$$
z=\frac{x-\mu}{\sigma}.
$$

K-Means сравнивает расстояния. Пропуски `absences` меняются от 0 до 75, а `studytime` — от 1 до 4; без масштабирования группы определялись бы почти только пропусками. После стандартизации у каждого признака среднее 0 и стандартное отклонение 1. Категориальные признаки переводятся в числа One-Hot кодированием: `internet = yes` → `internet_no = 0`, `internet_yes = 1`.

### Коэффициент силуэта

$$
s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))},
$$

где $a(i)$ — среднее расстояние до объектов собственного кластера, $b(i)$ — минимальное среднее расстояние до объектов другого кластера. Значения от −1 до 1. Для анкетных данных о людях типичны значения 0,1–0,3: группы размыты, граница условная. Это **не «естественные типы учеников»**, а удобное деление для анализа.

**Как выбирать $k$:** сопоставить три аргумента — «локоть» инерции, максимум силуэта и интерпретируемость (сможет ли учитель описать каждую группу словами; нет ли групп из 5–15 человек).

### Цели прогноза

$$
risk=
\begin{cases}
1, & G3<10,\\
0, & G3\geq10.
\end{cases}
\qquad
grade(G3)=
\begin{cases}
A, & 16\leq G3\leq20,\\
B, & 14\leq G3\leq15,\\
C, & 10\leq G3\leq13,\\
F, & 0\leq G3\leq9.
\end{cases}
$$

Оценки — по 20-балльной португальской шкале, 10 — порог «сдал». Шкала A/B/C/F — учебная, только для этой работы. Итоговый `G3 = 0` при ненулевых `G1`, `G2` обычно означает неявку на аттестацию, а не нулевые знания.

### Метрики классификации

| | прогноз «нет риска» | прогноз «риск» |
|---|---|---|
| на самом деле нет риска | TN | FP — лишняя консультация |
| на самом деле риск | **FN — ученик остался без помощи** | TP |

$$
Accuracy = \frac{TP+TN}{TP+TN+FP+FN},\qquad
Precision = \frac{TP}{TP+FP},\qquad
Recall = \frac{TP}{TP+FN},\qquad
F_1 = 2 \cdot \frac{P \cdot R}{P + R}.
$$

Для многоклассовой задачи (A/B/C/F):

$$
F_1^{macro}=\frac{1}{K}\sum_{k=1}^K F_{1,k}.
$$

**Почему Accuracy недостаточно.** В данных риск у 33 % учащихся; «модель», которая всегда отвечает «нет риска», уже получает Accuracy 67 %, не найдя ни одного ученика с риском. Для системы раннего предупреждения важнее Recall класса риска, но при очень низком Precision учитель утонет в ложных сигналах.

**Сравнение с правилом учителя.** В ноутбуке модель сравнивается с правилом «последняя известная оценка ниже 10» (`G2 < 10`; для варианта 11 — `G1 < 10`). Если модель с десятками признаков не лучше этого правила, её сложность не оправдана — это корректный и ценный вывод, а не провал.

## 5. Общий алгоритм

1. Загрузить `student-mat.csv` с `sep=';'`.
2. Проверить структуру, `NaN`, дубликаты, диапазоны и нули в `G1–G3`.
3. Взять признаки кластеризации своего варианта.
4. Числовые признаки масштабировать, категориальные кодировать One-Hot.
5. Для $k=2..8$ вычислить `inertia_` и коэффициент силуэта.
6. Выбрать $k$, сопоставив локоть, силуэт и интерпретируемость.
7. Обучить итоговый K-Means.
8. Построить профиль кластеров в исходных шкалах.
9. Определить кластер повышенного внимания по учебным признакам (низкие `G1`, `G2`; высокие `failures`, `absences`).
10. Проверить интерпретацию по доле `G3 < 10` — **только после кластеризации**.
11. Создать целевую переменную классификации и исключить `G3` и производные от него столбцы из признаков.
12. Выполнить стратифицированное `train_test_split` (25 % — тест, `random_state=42`).
13. Обучить модель своего варианта.
14. Рассчитать матрицу ошибок, Classification Report и сравнить с правилом учителя.
15. Интерпретировать $F_1$ и Recall класса риска.
16. Построить важность признаков; проверить модель без социально-демографических признаков.

| группа повышенного внимания | кластер 0: средние G1 = 8,1, G2 = 7,7; доля `G3 < 10` — 68,7 % (в кластере 1 — 7,0 %) |
| train / test | 296 / 99 |

## 8. Педагогический кейс: ИОМ

```mermaid
flowchart LR
    A[Прогноз риска] --> B[Проверка учителем]
    B --> C[Диагностика дефицитов]
    C --> D[Персональные задания]
    D --> E[Консультация]
    E --> F[Контроль посещаемости]
    F --> G[Повторная диагностика через 2 недели]
    G --> H{Есть прогресс?}
    H -- Да --> I[Снижение интенсивности поддержки]
    H -- Нет --> J[Корректировка ИОМ]
    J --> D
```

| Компонент ИОМ | Содержание | Пример (учащийся S012 из эталона) |
|---|---|---|
| Основание | учебные показатели, требующие педагогической проверки | G1 = 6, G2 = 7, 15 пропусков |
| Цель | конкретный результат на 2 недели | восстановить 2 темы, проверочная работа ≥ 6 из 10 |
| Диагностика | короткая диагностическая работа | 15 минут по темам второго периода |
| Учебный контент | 2–3 персональных задания | по 3 задания возрастающей сложности с образцом |
| Поддержка | консультация / парная работа / цифровой ресурс | 2 консультации по 20 минут, работа в паре |
| Посещаемость | план восстановления пропущенных тем | одна тема в неделю + мини-задание |
| Контроль | формирующее оценивание | тест в конце недели, обратная связь в тот же день |
| Критерий прогресса | измеримое улучшение | +2 балла из 10 по диагностике |
| Пересмотр | повторная оценка через 14 дней | при прогрессе — реже консультации, без прогресса — корректировка |

**Недопустимо** использовать риск-модель для автоматического снижения оценки, ограничения доступа к сложным заданиям, решений по полу, семье или образованию родителей, а также формулировки «неспособный», «слабый ученик».

Корректно: *The model indicates an elevated academic risk; the case should be reviewed by the teacher.*  
Некорректно: *The model proves that the student is weak and will fail.*

## 11. Контрольные вопросы и ориентиры ответов

| Вопрос | Ориентир ответа |
|---|---|
| 1. Почему K-Means требует масштабирования? | алгоритм сравнивает расстояния; признак с большим разбросом (пропуски) иначе подавит остальные |
| 2. Что означает `inertia_`? | сумма квадратов расстояний объектов до центров своих кластеров; уменьшается с ростом $k$ |
| 3. Чем метод локтя отличается от силуэта? | локоть смотрит только на плотность групп; силуэт — ещё и на отделённость от соседних групп |
| 4. Почему нельзя включать `G3` в признаки? | это ответ; модель «подсмотрит» его, и качество будет ложно высоким (утечка данных) |
| 5. В каком сценарии допустимы `G1` и `G2`? | только после второго периода, когда обе оценки уже выставлены |
| 6. Почему Accuracy недостаточно при дисбалансе? | ответ «никто не рискует» даёт высокую Accuracy при нулевом Recall |
| 7. Почему FN особенно важен для системы раннего предупреждения? | пропущенный ученик с риском не получит помощи вовремя; лишняя консультация (FP) почти не вредит |
| 8. Что важность признаков не позволяет утверждать? | что признак является причиной; она описывает только решения данной модели на данных наблюдения |
| 9. Почему кластер нельзя называть «слабыми учениками»? | это условная группа по нескольким показателям, силуэт низкий; ярлык стигматизирует и не следует из данных |
| 10. Почему ИОМ должен подтверждаться преподавателем? | модель не знает контекста (болезнь, неявка, семейные обстоятельства) и ошибается; ответственность за решение — у педагога |
